# Life Commander

Personal Life Operating System — visual prototype.

## Current phase
Design only. Functional implementation starts only after visual approval.

## Languages
English, Russian, Spanish, German, French.

All visible interface strings are defined through localization keys in `index.html`.

## Product model
Local-first, offline-capable architecture. No mandatory server, account, subscription or paid API.
